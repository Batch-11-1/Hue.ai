# StylehubReact
The frontend react app of the stylehub application

Instructions for using git

Starting the project
1 Open VS Code
2 Press Ctrl + Shift + P
3 Type: Git: Clone
4 Paste the repository URL: https://github.com/jerinmt/StylehubReact.git
5 Choose a folder where you want to save it
6 Click Open

Working on the project
1 In VScode terminal
  a)git pull origin main
  b)git checkout -b my-feature-name
2 Go to Source Control tab (left sidebar)
  a) Stage files (+ icon)
  b)Write commit message
  c)Click ✔️ (commit)
3 In VScode terminal
  git push origin my-feature-name
4 Go to the repo on GitHub:
  You’ll see a button: “Compare & pull request”
  Click it
  Add description
  Click Create Pull Request
