# Stylehub
Stylehub - an application to style(CSS) webpages in html, ejs, jsx files through AI.

Instructions for using git

Starting the project
1 Open VS Code

2 Press Ctrl + Shift + P

3 Type: Git: Clone

4 Paste the repository URL: https://github.com/jerinmt/Stylehub.git

5 Choose a folder where you want to save it

6 Click Open


Working on the project

1 In VScode terminal

  a)git pull origin main
  
  b)git checkout -b my-feature-name

  

2 After entering your code

  a) In VS code terminal type - git add .
  
  b)git commit -m "Enter a description"

  c) git push origin my-feature-name

  
4 Go to the repo on GitHub:

  a)You’ll see a button: “Compare & pull request”
  
  b)Click it
  
  c)Add description
  
  d)Click Create Pull Request
